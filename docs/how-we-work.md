# How We Work — A Quick Guide

This page explains the tools we use and why. **You don't need to be technical** — everything works in a regular web browser.

---

## The short version

| What | Tool | Why |
|---|---|---|
| Our website | [GitHub Pages](https://hrydbeck.github.io/PLmicRO/) | Free, always up to date, no IT support needed |
| Meeting notes | [HackMD](https://hackmd.io) | Everyone can type at the same time during a session |
| Paper suggestions & voting | [SharePoint List](https://ostergotland-my.sharepoint.com/personal/halfdan_rydbeck_regionostergotland_se/Lists/Paper%20Suggestions/AllItems.aspx) | Familiar to everyone at the region, easy voting with Likes |
| File storage & version history | [GitHub](https://github.com/hrydbeck/PLmicRO) | Keeps track of every change, nothing gets lost |
| Shared paper library | [Zotero](https://www.zotero.org/groups/plmicro) | Free reference manager, shared across the group |

---

## What is GitHub?

Think of it as a **shared folder with a memory**. Every file we use — reading lists, notes, primers — lives here. The difference from a normal shared drive is that GitHub remembers every version of every file, so nothing is ever lost.

**Do I need a GitHub account?** No. You can read everything on our website without one. If you want to suggest edits or propose papers via GitHub Issues, a free account helps — but the SharePoint list works fine for suggesting papers too.

---

## What is GitHub Pages?

It's what turns our files into the website you're reading right now. When we update a file, the website updates automatically within a minute or two. No web hosting, no IT tickets — it just works.

**Our website:** [hrydbeck.github.io/PLmicRO](https://hrydbeck.github.io/PLmicRO/)

---

## What is HackMD?

It's like **Google Docs for meeting notes**, but designed for the kind of formatted text we use (tables, code, links). During a session:

1. Someone shares the HackMD link
2. Everyone opens it in their browser
3. Everyone can type at the same time — you see changes live
4. After the session, the notes get saved back to GitHub (and the website updates)

**Do I need a HackMD account?** No — you can edit anonymously. An account lets you find your notes later, but it's optional.

## What do I actually need to do?

### Before a session
- Read the paper (linked from the [Reading List](https://hrydbeck.github.io/PLmicRO/reading-list/))
- Optionally look at the session notes for pre-reading questions

### During a session
- Open the HackMD link that's shared (it's also on the [Notes](https://hrydbeck.github.io/PLmicRO/notes/) page)
- Type your thoughts, questions, or notes — everyone edits the same document

### Between sessions
- Browse the website for primers, glossary, and archived notes
- [Suggest a paper](https://hrydbeck.github.io/PLmicRO/suggest/) if you find something interesting
- Vote on the [SharePoint list](https://ostergotland-my.sharepoint.com/personal/halfdan_rydbeck_regionostergotland_se/Lists/Paper%20Suggestions/AllItems.aspx) for papers you'd like to read
